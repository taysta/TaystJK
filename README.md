# TaystJK

TaystJK is a cross-platform Jedi Academy multiplayer client designed for regular use across Base JKA, JA+/JA++, jaPRO, and Lugormod servers. It pairs mod-aware compatibility with engine performance, stability, and practical quality-of-life improvements.

The project brings together authorized, credited work from several JKA community projects and maintains those ports as one coherent client. See the documentation's [source lineage](https://taysta.github.io/TaystJK/reference/sources/) for the projects represented in the current codebase.

This branch contains the documentation site at [taysta.github.io/TaystJK](https://taysta.github.io/TaystJK/).
